# Contributing

Please open an issue if you have an idea or feature that you wish to include in the project. If you want to also implement the feature, feel free to take ownership of the issue, but you must open an issue prior to your PR being accepted.

Majority or entirely LLM-generated code will be rejected. This has nothing to do with quality, and has to do with feature ownership. LLM assisted code does not need to be declared or disclosed and is accepted readily.
